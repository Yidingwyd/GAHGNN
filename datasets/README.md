The current directory contains the following datasets: Explicit Analytical Function, Ginzburg–Landau Model MC with r_phi = -1, Ginzburg–Landau Model MC with r_phi = 1, High-Entropy Alloy Catalyst, and the Nb-Based Alloy database.

Among them, the first three datasets were calculated or simulated by the authors of this paper. The High-Entropy Alloy Catalyst dataset was obtained by He through DFT calculations (if you use this dataset, please cite [his paper](https://github.com/xianghe91/HEAML)). For the Nb-Based Alloy database, only the data generated through data augmentation are provided.

In each folder, the 0 subfolder contains the 1-uniform GAHGNN model and the corresponding main-effect results. The 0-0 subfolder contains the 2-uniform GAHGNN model and the corresponding pairwise interaction-effect results. The 0-0-0 subfolder contains the 3-uniform GAHGNN model and the corresponding third-order interaction-effect results.
